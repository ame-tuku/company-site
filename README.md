# スカイライン・テクノロジーズ コーポレートサイト

スカイライン・テクノロジーズは、長く動き続ける業務システムを設計・開発するソフトウェア開発会社です。
本リポジトリは、その企業サイトのソースコードを管理しています。

## 構成

- `index.html` — サイトのトップページ(単一のHTMLファイル)

## 表示方法

このサイトは静的なHTMLファイルのため、サーバーを立てなくてもブラウザで直接開くことができます。

1. リポジトリをクローン、またはダウンロードする
2. `index.html` をブラウザ(Chrome、Safari、Firefoxなど)にドラッグ&ドロップ、またはダブルクリックして開く

コマンドラインから開く場合は以下を実行します。

```bash
open index.html
```
